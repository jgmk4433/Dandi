# PM 헬멧 미착용 단속 시스템 — 지역 서버 (Regional Server)

## 개요
중앙 허브로부터 배정된 단속 건에 대해 최종 판별을 수행하고, 확정된 위반 사건을 처리하는 지역 단위 서버입니다. 이미지 기반 정밀 판독과 담당자 수동 검수를 결합해 판정 정확도를 높이는 역할을 합니다.

## 주요 기능
- **단속 건 수신 API**: 중앙 허브가 전달한 신고 건과 이미지를 수신·저장합니다.
- **정밀 영상 판별**: 로컬 비전-언어모델(VLM)을 활용해 안전모 착용 여부, 동승 인원 등을 최종 확인합니다.
- **관심 영역 판독**: 허브가 지정한 좌표를 기준으로 필요한 부분만 확대 판독해 정확도를 높입니다.
- **수동 검수 화면**: 자동 판별이 확신하지 못한 사건을 담당자가 직접 확인·확정할 수 있는 웹 화면을 제공합니다.
- **이의제기 처리**: 시민의 이의신청을 접수해 재심의 대기열에 등록합니다.
- **결과 통보**: 확정된 심의 결과를 중앙 허브로 통보합니다.
- **사건 조회 API**: 사건번호로 심의 진행 상황과 결과를 조회할 수 있습니다.

## 시스템 구성
```
중앙 허브  →  지역 서버  →  담당자 수동 검수 화면
                 ↓
           로컬 VLM 판별 엔진
```
- **API 서버**: FastAPI 기반 REST API
- **저장소**: SQLite 데이터베이스, 로컬 이미지 저장소
- **작업 처리**: 백그라운드 워커를 통한 비동기 처리
- **정밀 판독**: Ollama 기반 로컬 비전-언어모델(VLM)
- **검수 화면**: 서버 렌더링 방식의 관리자 웹 페이지

## 기술 스택
Python · FastAPI · SQLAlchemy · Ollama (VLM) · Pillow · httpx

## 실행 방법
```bash
# 사전 준비: Ollama 실행 및 모델 설치
ollama serve
ollama pull qwen3-vl:7b

# 환경 점검
python main.py --check

# 서버 실행
python main.py
```

## 프로젝트 구조
```
app/
 ├─ api/         API 라우터 (수신, 사건 조회, 검수, 시스템)
 ├─ core/        공통 유틸리티 (작업 큐, 이미지 처리)
 ├─ services/    핵심 처리 로직 (VLM 판별, 허브 통신)
 ├─ config.py    환경 설정
 ├─ database.py  DB 연결 관리
 ├─ models.py    데이터 모델 정의
 └─ server.py    FastAPI 앱 구성
main.py          실행 진입점
```
