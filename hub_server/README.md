# PM 헬멧 미착용 단속 시스템 — 중앙 허브 (Central Hub)

## 개요
전동킥보드(PM) 이용자의 안전모 미착용 및 정원 초과 탑승을 자동으로 감지·단속하기 위한 시스템의 중앙 허브 서버입니다. 시민 제보 앱으로부터 신고를 접수하여 1차 영상 판독을 수행하고, 판정 결과에 따라 각 지역 서버로 사건을 배정·전달하는 역할을 담당합니다.

## 주요 기능
- **신고 접수 API**: 앱에서 업로드한 신고 이미지와 메타데이터를 받아 접수 번호를 발급합니다.
- **1차 영상 판독**: YOLO 객체 탐지 모델로 탑승 여부, 안전모 착용 여부, 동승 인원을 분석해 위반 여부를 1차 판정합니다.
- **지역 서버 연계**: 판정 결과를 관할 지역 서버로 전달하고, 처리 상태를 실시간으로 추적합니다.
- **처리 상태 조회**: 앱에서 신고 건의 접수·심의 진행 상황을 조회할 수 있습니다.
- **이의제기 중계**: 시민이 제기한 이의신청을 관할 지역 서버로 전달합니다.
- **심의 결과 반영**: 지역 서버의 최종 심의 결과를 수신해 이력에 반영합니다.
- **재학습 데이터 수집**: 판정 결과가 엇갈린 사례를 자동으로 모아 모델 개선에 활용합니다.
- **실시간 모니터링**: 접수 현황, 지역 서버 상태, 처리 이력을 한눈에 보여주는 데스크톱 모니터를 제공합니다.

## 시스템 구성
```
시민 제보 앱  →  중앙 허브  →  지역 서버(다수)
                    ↑↓
              실시간 모니터 UI
```
- **API 서버**: FastAPI 기반 REST API
- **저장소**: SQLite 데이터베이스, 로컬 이미지 저장소
- **작업 처리**: 백그라운드 워커를 통한 비동기 처리
- **영상 판독**: YOLO 기반 객체 탐지 모델
- **모니터링**: PySide6 기반 데스크톱 애플리케이션

## 기술 스택
Python · FastAPI · SQLAlchemy · Ultralytics YOLO · PySide6 · httpx

## 실행 방법
```bash
# 서버 + 모니터 UI 함께 실행
python main.py

# 서버만 실행 (원격 배포 환경)
python main.py --no-ui
```

## 프로젝트 구조
```
app/
 ├─ api/         API 라우터 (신고 접수, 이의제기, 콜백, 시스템)
 ├─ core/        공통 유틸리티 (작업 큐, 이미지 처리, 식별자 발급 등)
 ├─ services/    핵심 처리 로직 (영상 판독, 지역 서버 연동)
 ├─ ui/          모니터링 데스크톱 화면
 ├─ config.py    환경 설정
 ├─ database.py  DB 연결 관리
 ├─ models.py    데이터 모델 정의
 └─ server.py    FastAPI 앱 구성
main.py          실행 진입점
```
